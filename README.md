# 🌍 Atlas Website

> AI-Assisted conference website for Atlas Conference — built for African business and event audiences.

---

## 📌 Overview

The **Atlas Conference Website** is the public-facing marketing and event platform for the Atlas Conference. It serves as the primary entry point for attendees, sponsors, and speakers.

- **Owner:** Ali Mora
- **Location:** Johannesburg, ZA
- **Updated:** 2026-03-29

---

## 🎯 Mission

Deliver a polished, high-performance conference website that showcases the Atlas Conference brand, drives registrations, and provides key event information — built with Next.js and deployed via Netlify.

## 📋 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
